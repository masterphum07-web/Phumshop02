แจ้งเตือนผ่าน LINE

เมื่อมีการอัปโหลดไฟล์ใหม่ ระบบจะส่งข้อความเข้า LINE อัตโนมัติ — ปล่อยว่างไว้ทั้งหมด = ปิดใช้งาน

📖 วิธีสมัครใช้งาน (กดเปิดดู)
  1. เข้า developers.line.biz → สมัครบัญชี (ใช้ LINE ที่ล็อกอินอยู่ได้เลย)
  2. สร้าง Provider (ชื่ออะไรก็ได้) → สร้าง Channel ประเภท Messaging API
  3. ในหน้า Messaging API → กด Issue ที่ Channel access token → ก๊อปมาวางในช่องซ้ายบน
  4. แชร์ QR ของบอทให้เพื่อนๆ กดเพิ่มเพื่อน (อยู่ในหน้า LINE Official Account Manager) — ต้องมีคนเพิ่มอย่างน้อย 1 คน ไม่งั้นส่งไม่ได้
  5. กด "ทดสอบส่งข้อความ" ถ้าไลน์เด้ง = เสร็จ! (ฟรี 200 ข้อความ/เดือน)
